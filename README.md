# التزام برو - نظام الحسابات الذكي

**التزام برو** هو واجهة ويب متكاملة تعمل داخل بوت تيليجرام، صُممت لإدارة الحسابات والصناديق والقيود المحاسبية بسهولة واحترافية.

## 🎯 الهدف من المشروع
- تسجيل القيود المحاسبية اليومية (دائن/مدين)
- إدارة حسابات العملاء والموردين
- متابعة الصناديق المالية والتحويلات بينها
- إصدار فواتير الكهرباء والماء والمبيعات
- متابعة الديون وجدولة الأقساط
- إرسال إشعارات واتساب تلقائية للعملاء (يحتاج ربط جلسة واتساب)

## 📦 ما يحتويه المشروع
الملف الرئيسي هو `index.html` ويحتوي على:
- تصميم عصري كامل (Dark UI) بألوان جذابة
- جميع الصفحات والخدمات مبنية داخل الملف نفسه
- نوافذ منبثقة للبحث عن الحسابات واختيار العملة
- محاكاة لمعظم العمليات (يمكن ربطها بقاعدة بيانات حقيقية مثل Google Sheets)

## 🚀 كيفية التشغيل
1. **للاستخدام المباشر:** افتح ملف `index.html` في متصفحك.
2. **للاستخدام داخل تيليجرام:**
   - ارفع الملف إلى مستودع GitHub وفعّل GitHub Pages.
   - استخدم الرابط الناتج كـ Web App URL في بوت تيليجرام (عبر BotFather).
3. **للحفظ الحقيقي للبيانات:** اربطه بـ Google Sheets أو أي خادم خلفي.

## 💡 مميزات النسخة الحالية
- دعم العملات (يمني، سعودي، دولار)
- كاميرا لتصوير العدّادات والباركود (تعمل داخل تيليجرام)
- البحث عن جهات الاتصال
- تفقيط المبلغ تلقائياً (كتابة المبلغ بالحروف العربية)
- تأثيرات حركية وتفاعلية سلسة

## 📝 ملاحظة
هذه نسخة أمامية (Frontend) جاهزة تماماً للاستخدام المباشر. لحفظ البيانات بشكل دائم، يمكن ربطها بسهولة مع Google Sheets أو أي قاعدة بيانات خارجية.
